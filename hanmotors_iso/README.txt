HANMOTORS — сайт-визитка, раздельная структура файлов
=========================================================

Структура:
  index.html                — разметка страницы
  css/main.css              — оформление и адаптивная вёрстка
  js/main.js                — мобильное меню, прокрутка и активная навигация
  assets/img/workshop.webp  — изображение главного блока

Названия папок нормализованы согласно общепринятой веб-практике:
assets (а не assest), js/main.js (нижний регистр).

Установка:
1. Распакуйте архив.
2. Загрузите ВСЕ файлы с сохранением структуры каталогов на хостинг
   (например, в /EPROM_R8/).
3. Для локального просмотра откройте index.html в браузере.
4. Ссылки на CSS, JavaScript и картинку относительные; менять их не нужно.

Перед публикацией:
- В прайсе указаны ДЕМОНСТРАЦИОННЫЕ цены; замените на подтверждённые.
- Сверьте телефон, адрес и Instagram с фактическими контактами.
- Шрифты Google Fonts грузятся из интернета, при отсутствии сети есть запасные.

Сайт сохранён без визуальных и функциональных изменений относительно предыдущего варианта.
